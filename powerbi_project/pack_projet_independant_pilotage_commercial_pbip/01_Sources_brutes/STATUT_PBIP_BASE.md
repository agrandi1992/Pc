# Statut du PBIP de base

Aucun fichier `.pbip`, `.pbix` ou `.pbit` de base n’a été fourni dans les fichiers disponibles du projet.

Le pack contient donc :
- le modèle sémantique original `.bim` ;
- le référentiel KPI Excel ;
- la maquette HTML ;
- les images de référence ;
- les spécifications Power BI ;
- les DAX et scripts de validation.

Le livrable attendu de l’agent / développeur est de **créer un nouveau projet Power BI `.pbip`** en s’appuyant sur ces sources.

Si un `.pbip` de base existe côté utilisateur, il faut l’ajouter dans ce dossier avant de lancer le build.
