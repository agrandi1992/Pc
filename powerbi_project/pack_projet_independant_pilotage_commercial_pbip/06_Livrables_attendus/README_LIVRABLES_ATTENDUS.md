# Livrables attendus du projet PBIP

Le développeur / agent doit produire dans ce dossier ou dans un dossier équivalent :

1. `Pilotage_Commercial.pbip`
2. Dossier du projet Power BI associé au `.pbip`
3. Modèle sémantique enrichi
4. Toutes les pages du rapport
5. `CHANGELOG_BUILD.md`
6. `KPI_STATUS_FINAL.md`
7. `RAPPORT_VALIDATION_OVERLAP.md`
8. Captures PNG finales des pages
9. DAX final exporté ou documenté
10. Notes sur les éléments non raccordables faute de source Gold / fact absente

## Règle d’honnêteté
Si un élément ne peut pas être alimenté car la table n’existe pas dans le modèle ou dans la couche Gold, il faut le dire explicitement et ne pas simuler une donnée réelle.
