# DÉPLOIEMENT DIRECT LAKE — TABULAR EDITOR 3
# Pilotage Commercial — Guide de déploiement

## PRÉREQUIS
- Tabular Editor 3 (TE3)
- Accès workspace Fabric : faw-partners-smart-data-dev
- Fichier : DEPLOY_TMSL_DirectLake.xmla (dans ce dossier)

═══════════════════════════════════════════════════════
## ÉTAPE 1 — Connexion XMLA dans TE3
═══════════════════════════════════════════════════════

1. Ouvrir Tabular Editor 3
2. File > Open > Analysis Services Database...
3. Server :  powerbi://api.powerbi.com/v1.0/myorg/faw-partners-smart-data-dev
4. Authentication : Azure Active Directory (votre compte Microsoft Fabric)
5. Database : Pilotage_Commercial → OK

═══════════════════════════════════════════════════════
## ÉTAPE 2 — Exécuter le TMSL (createOrReplace)
═══════════════════════════════════════════════════════

1. Dans TE3, menu : View > XMLA Query / ou Ctrl+Shift+Q
2. Ouvrir le fichier DEPLOY_TMSL_DirectLake.xmla
   (ou copier-coller son contenu dans la fenêtre XMLA Query)
3. Cliquer sur ▶ Execute (ou F5)
4. Attendre le message : "The commands completed successfully"

⚠️ NE PAS utiliser "Deploy workspace database" — utiliser uniquement le XMLA Query

═══════════════════════════════════════════════════════
## ÉTAPE 3 — Lier au Lakehouse lh_gold dans Fabric
═══════════════════════════════════════════════════════

1. Ouvrir le workspace Fabric : faw-partners-smart-data-dev
2. Cliquer sur Pilotage_Commercial (Semantic model)
3. Settings (icône engrenage) > Data source credentials / DirectLake settings
4. Sélectionner le Lakehouse : lh_gold
5. Sauvegarder

═══════════════════════════════════════════════════════
## ÉTAPE 4 — Rafraîchissement
═══════════════════════════════════════════════════════

1. Dans le workspace : Pilotage_Commercial > ... > Refresh now
2. Attendre la fin du refresh
3. Le modèle est maintenant en mode Direct Lake ✅
