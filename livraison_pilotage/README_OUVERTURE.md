# ouverture du rapport V5

1. Extraire le zip dans un chemin court, par exemple `C:\PBI\CAPFINANCES_V5`.
2. Ouvrir `Pilotage_Commercial.pbip` avec Power BI Desktop.
3. Vérifier d'abord sans refresh pour contrôler le rendu PBIR.
4. Contrôler les pages dans cet ordre :
   - vue d'ensemble
   - performance commerciale
   - suivi des affaires
   - réseau MIA et géographie
   - suivi des rendez-vous
   - mandataires
   - alertes commerciales
   - glossaire des indicateurs
5. Vérifier que le canvas est bien en format large 1536 x 961.
6. Tester les filtres V5 : assureur, centre d'affaires, ancienneté, client/prospect, présentiel/visio.

La V5 améliore la conformité visuelle et réduit les placeholders, mais le contrôle final Power BI Desktop reste obligatoire.
